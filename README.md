# Xiaomi CameraTuner

小米相机调校工具（LSPosed 模块）

在小米 15 / 17 系列机型上运行 18 Pro Max 的相机包时，补齐缺失的功能与体验修复。

> **当前版本：v1.9** ｜ 相机包 6.8.002090.2

### 支持机型

焦段预设已内置以下 11 款机型：

| 系列 | 机型 |
|---|---|
| 15 系列 | 15 ｜ 15 Pro ｜ 15s Pro ｜ 15 Ultra |
| 17 系列 | 17 ｜ 17 Pro ｜ 17 Pro Max ｜ 17 Max ｜ 17T ｜ 17T Pro ｜ 17 Ultra |

> 实测机型为 **小米 15 Pro**，其余机型按官方镜头参数配置，尚未逐一验证。如有偏差欢迎反馈。

## 功能介绍

### 核心功能

| 功能 | 说明 |
|---|---|
| 机型伪装 | 让相机认为自己是 18 Pro Max (madrid)，避免启动后自动退出 |
| 传奇一瞬能力门 | 强制 LegendBokehCapsInfo 返回 true（默认关闭，不了解请勿开启） |
| 原色风格 | 解锁「原色」色彩风格，新增第三档可选（原色 / LEICA 生动 / LEICA 经典），默认关闭 |
| 片门全开 | 专业录像可输出 4096×3072 全画幅（4:3 全传感器） |
| 移轴开关 | 相机左上角悬浮控制，支持圆形 / 平行两种移轴 |
| 动态照片 + 超级长焦 | 开启超级长焦时也能同时拍动态照片，两者不再互斥（默认关闭） |
| 调色盘成片修复 | 让「原图」档的色盘参数真正作用到成片，不再只有预览生效 |

### 传奇色彩

18 Pro Max 的传奇一瞬色彩算法位于 HAL 层，本机没有对应实现，因此映射到相机自带的 LUT 滤镜管线来实现近似效果。

| 风格 | 默认滤镜 | 说明 |
|---|---|---|
| 黑白胶片 | 86 黑白 400 | 推荐，实测最接近 |
| 当代经典 | 73 自然 | 彩色，效果与原机有差异 |
| 传奇 CCD | 84 柯达 64 | 彩色，效果与原机有差异 |

三档滤镜均可通过「滤镜选择器」单独更换（42 款可选，带中文名与效果说明），也可一键恢复默认。

> 说明：色彩在预览与成片中生效，属于近似模拟，非原机 HAL 算法。

### 滤镜选择器

内置 42 款相机 LUT 滤镜，分四组：

| 分组 | 数量 | 示例 |
|---|---|---|
| 胶片复古 | 15 | 负片、胶片、富士 50、柯达 64 / 200、黑白 400 |
| 人像日常 | 14 | 日系、自然、繁花如梦 |
| 基础自然 | 7 | — |
| 美颜视频 | 6 | — |

每一款都带三段渐变色条预览、中文名称和效果描述。

### 水印

| 功能 | 说明 |
|---|---|
| 自定义水印机型 | 修改水印上显示的机型名称（留空则使用默认） |
| AI 水印 | 绕过机型限制，让 AI 水印功能可用 |

> 注：照片中烧进像素的品牌标识无法修改，本功能仅影响水印文字与预览。

### 模式

| 功能 | 说明 |
|---|---|
| 模式可见性 | 强制显示 / 隐藏相机的任意模式（夜景、超级月亮、电影、导演模式、Vlog 等） |
| AI 帮拍 | 移除机型限制，避免提示不匹配后自动退出 |
| 超级月亮 / 夜景 | 按需开启 |

### 焦段

| 功能 | 说明 |
|---|---|
| 机型预设 | 内置 11 款小米机型的推荐焦段，一键套用（含焦段重映射 + 档位剔除 + 循环档位表） |
| 焦段重映射 | 把 18 Pro Max 的镜头档位映射到本机实际镜头 |
| 档位剔除 | 移除不需要的档位（支持按模式） |
| 档位循环修正 | 修复到达最大档位后继续点击会乱跳的问题 |
| 专业模式长焦修复 | 修复专业模式下点 5x 无法调用长焦镜头的问题 |

小米 15 Pro 参考档位：拍照 `0.6 / 1 / 2 / 5 / 10`，人像 `1 / 2 / 5 / 10`，专业 `0.6 / 1 / 5 / 10`。

### 智能构图

修复智能构图按钮不可用的问题，**实验性**支持档位 1~7，尚未完整实测。

> 注：「网络不佳，无法识别当前场景」属于云端服务问题，与本模块无关。

### 应用功能

- 配置文件自动生成、编辑、备份、重建（缺项自动补齐）
- 状态页显示设备信息、模块运行状态、hook 加载数量
- 检查更新（云端版本比对）
- 更新日志查看
- 一键重启相机进程

## 安装步骤

1. 安装本模块 APK
2. 在 LSPosed / Vector 中启用模块
3. 作用域勾选「相机」(com.android.camera)
4. 打开本应用，授予「所有文件访问」权限
5. 点击「重启相机进程」
6. 首次启动相机后会自动生成配置文件

配置文件路径：

```
/sdcard/CameraTuner/config.conf
```

> **重要**：修改配置后必须重启相机进程才生效。若在「关于」页重建配置文件，请务必按提示操作——删除后立即强制停止相机，否则期间任何写入都会生成残缺文件。

## 配置说明

配置文件首次启动相机时自动生成，包含注释说明。版本升级后新增的配置项会自动补齐，已有值不受影响。

### 常用配置项

```conf
# 机型伪装
fake.enable=1
fake.device=madrid
fake.model=2611FPNFAG

# 原色风格（0=关，1=开）
cvtype.natural=0

# 传奇色彩滤镜（m3=黑白胶片 / m10r=当代经典 / m9=传奇CCD）
legend.filter.m3=86
legend.filter.m10r=73
legend.filter.m9=84

# 移轴开关（0=关，1=开）
tilt.switch=0

# 动态照片 + 超级长焦（0=关，1=开）
live.supertele=0

# 调色盘成片修复（0=关，1=开，默认开）
tone.fix=1

# 智能构图（实验性）
smartcomp.enable=0

# 模式可见性（可写多行）
enable_mode=com.android.camera.features.mode.night.photo.NightModuleEntry
enable_mode=com.android.camera.features.mode.moon.MoonModuleEntry

# 焦段重映射
zoom.enable=1
zoom_remap=0.7:0.6,3.2:5.0,6.4:10.0
zoom.drop=4.3

# 机型预设（写入设备代号，使用「机型预设」按钮时自动设置）
zoom.preset=haotian

# 专业模式长焦修复
legend.prolens=1
legend.prolens_modes=167
```

## 已知问题

| 问题 | 说明 |
|---|---|
| 萌拍（Mimoji）切换造型闪退 | 18 相机把「徕卡一瞬」塞进了 Mimoji 造型列表，而 Mimoji 的 Context 无法解析该资源。属相机包移植不完整，非本模块可修。 |
| AI 水印进入闪退 | 水印数据源为空（`LM1/b.c()` 中三道能力门均返回 false），即使强制抬门，列表仍为空。需相机包提供完整数据。 |
| 导演模式功能残缺 | 布局中缺少多个控件；参数调节（EV/ISO 等）调用已废弃的 `HorizontalScaleZoomView`，绘制时崩溃。当前仅可进入并录制视频，不可修改参数。 |
| 部分焦距索引需手动配置 | 不同相机版本的混淆类名可能变化，若长焦无法调用，可在「高级参数」中调整镜头索引。 |
| 传奇一瞬无法输出 RAW | 相机 HAL 为 15 Pro 专属编译，策略表中不存在「传奇一瞬 + RAW」组合，Java 层修改无法绕过。 |
| 智能构图未完整验证 | 按钮已可点亮，但构图框是否实际出现尚未完整实测。 |
| 5000 万像素模式卡死 | 已知问题，暂未定位。 |
| 功耗偏高 / 发热 | 18 相机包运行在 15 Pro 上存在硬件差异（ISP 代差），非模块问题。 |
| 关闭模块后状态页误报 | 状态页判断依据为「配置文件存在且 hook 数 > 0」，关闭模块后不重启相机可能仍显示运行中。 |

## 构建

本项目**不使用 Gradle**，采用命令行手工构建，大致流程：

1. `aapt2 compile` 编译 `res/` 生成资源包
2. `aapt2 link` 生成 `R.java`
3. `javac` 编译源码与 `R.java`（需 `android.jar` 与 Xposed API jar）
4. `d8` 将 class 转成 `classes.dex`
5. `aapt2 link` 带 `assets/` 打包为 APK，并将 `classes.dex` 置于 APK 根目录
6. `jarsigner` 或 `apksigner` 签名

> 本仓库**不提供一键构建脚本**。上述依赖需自行准备，混淆类名与资源索引在不同相机版本间存在差异，构建产物请自行验证。
