# Xiaomi CameraTuner

小米相机调校工具（LSPosed 模块）
在小米 15 Pro 上运行 18 Pro Max 相机包时的功能补齐与修复。

## 功能

- 机型伪装（madrid）
- 模式可见性（夜景 / 超级月亮 / 电影 / 导演模式等）
- AI 水印
- 片门全开（4096×3072）
- 专业模式长焦修复
- 焦段重映射 / 档位循环修正

## 安装

1. 安装 APK
2. LSPosed 启用模块，作用域勾选「相机」
3. 打开 App 授予文件访问权限
4. 点「重启相机进程」

配置路径：`/sdcard/CameraTuner/config.conf`

## 已知问题

- 萌拍 / AI 水印：相机包移植不完整，无法修复
- 导演模式：仅可录制，参数调节会崩
- 传奇一瞬：无法输出 RAW（HAL 限制）
